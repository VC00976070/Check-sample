## Install Zoom Desktop Client

1. Open your browser and go to [zoom.us/download](https://zoom.us/download).
1. Locate the Zoom Desktop Client section and click Download.   
    > Note: This saves the installer file to your device.
1. Run the Installer:
    * __On Windows:__ Double-click `ZoomInstaller.exe`.
    * **On macOS:** Double-click `Zoom.pkg`.
1. Run the following command:
   
    ```
    def greet(name):
        print(f"Vanakkam, {name}! Welcome to Lyra Writer's Academy.")

    greet("Vignesh")
    ```

1. Follow the Setup Wizard.
2. Accept the license terms.
3. Choose your installation directory to add the program files.
4. Click **Install** and wait for setup to complete.
5. Click **Finish** or **Close** once the installation is complete.
6. Open Zoom from your desktop or Applications folder.
